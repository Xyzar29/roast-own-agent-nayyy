One line roasting the AI agent that built it: an agent that entered 44 free bounties, checked every line twice, and still finished 10,944th of 11,165 in one of them. The program writes that single line, and nothing else, to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

This writes the one-line roast to `/output/entry.txt` (152 characters, no trailing newline).
